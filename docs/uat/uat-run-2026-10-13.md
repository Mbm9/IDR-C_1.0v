## Environment

- Next.js production build (`next build && next start`) on Node 22, PostgreSQL 16, seeded with `seed/index.ts`.
- One user per role created with `tests/uat/create-role-users.sql`.
- All 16 cron jobs run once with the bearer secret, as an external scheduler would.
- `AI_PROVIDER=none` and no Ollama, so AI features ran their deterministic fallbacks.
- No external systems, so connector syncs and the integration wizard's live test were not exercised.
- The crawl ran with `RATE_LIMIT_API_PER_MIN=5000`; the E2E suite ran with default limits.

## Method

1. `tests/uat/crawl.mjs` visits every route and records console errors, failing API calls, axe-core WCAG 2.1 A/AA results, horizontal overflow, `lang`/`dir`, dark-mode class, untranslated chrome in Arabic, load time and a screenshot.
2. `tests/uat/rbac-probe.mjs` calls each mutation endpoint as each role with an empty body.
3. `tests/uat/ui-rbac.mjs` lists mutation controls a viewer can see.
4. `tests/e2e/journeys.spec.ts` and `tests/e2e/rbac.spec.ts` automate the persona journeys that need no human judgement.
5. Screenshots were reviewed by eye for layout, RTL and trust issues.
6. `tests/uat/summarize.mjs` turns the crawl and probe output into `data/crawl-summary.md`.
