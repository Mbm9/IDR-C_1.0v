# Branding

Show your organization's logo and name instead of the Identity Radar shield and name.

**Who can change it:** admins only. Every change is recorded in the audit trail as **Manage Branding**.

## Set the logo and name

1. Go to **Settings → Organization**.
2. Under **Branding**:
   - **Display name**: up to 60 characters. Leave it empty to show "Identity Radar".
   - **Logo**: upload a PNG, JPEG, WebP or SVG image of up to 256 KB. A square logo with a transparent background works best.
3. Check the **Preview**, then select **Save branding**.

To go back to the defaults, clear the name, select **Remove logo**, and save.

## Where it appears

| Place | Name | Logo |
|---|---|---|
| Sidebar | Yes | Yes |
| Browser tab title (signed-in pages) | Yes | — |
| Sign-in and sign-up pages | Yes* | Yes* |
| PDF reports (Risk Summary, Audit Trail, Compliance) | Footer | Header, PNG or JPEG only |

\* Only when the installation has a single organization, so one organization's branding is never shown to another organization's users before they sign in.
